# Osiyatech Services Knowledge Base — Draft v3.0

This package contains the service records extracted from the supplied `Osiyatech_Services_Knowledge_Base_v3.pdf`.

Each service folder contains:
- `service.md`: service record content before the FAQs section.
- `faqs.md`: service FAQ content, preserving `[drafted]` markers.
- `metadata.json`: document metadata and source page range.

**Important:** The PDF contains 15 service records, not 14. All 15 are included. Every record remains `draft`; do not ingest it into the public chatbot until reviewed and approved. The PDF's general review notes on pages 85–86 should also be resolved before launch.
