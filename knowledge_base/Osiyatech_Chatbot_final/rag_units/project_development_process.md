# Project Development Process

## [PROCESS-001] Osiyatech 6-stage delivery methodology
**Subcategory:** Delivery Lifecycle

**Related Questions:** What is your process?

Discover: Map user workflows, data models, constraints and business goals before writing code. Architect: Database schemas, API contracts, cloud topology and UX wireframes. Build: Focused 2-week sprints with working software demos every other Friday and direct Slack updates. Validate: Automated test suites, peer code reviews, load benchmarks and hands-on QA before any release. Launch: Production deployment with automated CI/CD pipelines and rollback readiness (described on the site as 'zero-downtime'). Scale: Proactive monitoring, performance tuning, security patches and new features as traffic grows.

## [PROCESS-003] Osiyatech engagement models
**Subcategory:** Engagement Models

**Related Questions:** Do you offer fixed price?, What engagement models do you have?

Dedicated Engineering Team (Best for continuous roadmaps): An autonomous engineering pod with senior developers, architects and QA shipping product features continuously. Fixed Scope Milestones (Best for scoped MVPs & platforms): Delivery timeline, clear milestone deliverables and a transparent budget (the site promises 'no surprise costs'). Extended Engineering Pod (Best for team augmentation): Senior developers and architects embedded in the client's existing sprint rituals and standups. Discovery & Architecture (Best for complex modernization): A technical audit, database blueprint, security review and cost estimate before building starts. Start a Project FAQ: both fixed-scope contracts and dedicated agile squads are offered.
