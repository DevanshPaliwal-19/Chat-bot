# Intellectual Property and NDA

| Field | Value |
|---|---|
| Document IDs | POLICY-013, POLICY-014 |
| Category | Policies |
| Source URL | https://ayushitated.com/hire-experts ; https://ayushitated.com/ui-ux-design ; https://ayushitated.com/mobile-development ; https://ayushitated.com/ ; https://ayushitated.com/hire-experts |
| Verification Status | Documented (service-level) / Partially documented |
| Last Reviewed | 2026-11-02 |

- Hire Experts: clients retain 100% IP ownership of all source code, architecture documentation, design files and database schemas created by Osiyatech developers from day one, backed by comprehensive NDAs.
- UI/UX: clients retain 100% IP of Figma files, research documentation, wireframes, icon sets and design tokens upon completion; no proprietary lock-ins or recurring licensing fees.
- Mobile: clients retain 100% IP of source code, design systems and database schemas; apps are deployed under the client's Apple Developer and Google Play Console accounts.
- Home: 'ownership of agreed project deliverables'.

**Not documented:** NDA process for general project enquiries; contract terms. Confirm with the Osiyatech team.
