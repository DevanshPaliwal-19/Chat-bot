# API reference

Base URL `http://127.0.0.1:8000`. Interactive docs: `/docs`. Errors always use
`{"error": {"code": "...", "message": "...", "request_id": "..."}}` and every response carries `X-Request-ID`.
IDs (`session_id`, `conversation_id`, `client_message_id`) are 8–64 chars of `[A-Za-z0-9_-]` generated by the client.
Admin endpoints need header `X-Admin-Key: <OSIYA_ADMIN_API_KEY>` and are disabled (403) when no key is configured.

| Method & path | Purpose |
|---|---|
| `GET /health` | LLM status (`ok`/`model_missing`/`unavailable`), index readiness, index version |
| `GET /config` | Public branding, limits, feature flags (voice in/out), handoff capability |
| `POST /api/v1/chat` | One text turn (any `interaction_mode`) |
| `GET /api/v1/conversations/{id}` | Visible history (requires `X-Session-ID` matching the owner) |
| `DELETE /api/v1/conversations/{id}` | Clear a conversation (same ownership check) |
| `POST /api/v1/audio/transcribe` | Multipart `file` → transcript + confidence |
| `POST /api/v1/audio/synthesize` | `{text}` → `audio/wav` |
| `POST /api/v1/audio/process` | Multipart voice turn: STT → engine → optional TTS (`with_audio`) |
| `POST /api/v1/leads` | Save a lead; `consent: true` is required |
| `GET /api/v1/leads` · `PATCH /api/v1/leads/{id}/status` | Admin |
| `POST /api/v1/knowledge/ingest` · `GET /api/v1/knowledge/status` | Admin |

## POST /api/v1/chat
```json
{"session_id": "s_abc12345", "conversation_id": null, "message": "Do you build chatbots?",
 "interaction_mode": "text", "client_message_id": "m_0001"}
```
Response: `message`, `conversation_id`, `sources[]` (index, title, source_document, source_url, page_number, snippet),
`confidence {level, score}`, `suggested_actions[]` (`open_lead_form`, `request_human_handoff`), `lead_status`,
`duplicate` (true when the same `client_message_id` is replayed – no second LLM call), `conversation_restarted`, `timings_ms`.

Status codes: 400/422 invalid input · 403 ownership/admin · 404 unknown conversation · 413 too large · 415 bad audio type ·
429 rate limited (`Retry-After`) · 503 model/service unavailable or busy · 504 timeout.

```powershell
Invoke-RestMethod -Uri http://127.0.0.1:8000/api/v1/chat -Method Post -ContentType "application/json" `
  -Body '{"session_id":"s_abc12345","message":"What services do you offer?"}'
```
